# Give-AID — NGO Donation & Welfare Portal

> **Every Rupee Reaches Those in Critical Need.**

Give-AID is a complete **NGO Donation & Welfare Management System** developed using **ASP.NET Core MVC**. The platform is designed to manage donations, welfare causes, programmes, donors, NGO partners, users, payment verification, reports, queries, and administrative activities through a centralized web portal.

The project includes both a public-facing donation portal and a powerful administration dashboard for managing the complete NGO workflow.

---

## 🌐 Live Demo

🔗 http://give-aid-ngo-management-system.runasp.net/

## 📌 Project Overview

Give-AID provides a digital platform where visitors and donors can explore welfare causes, register accounts, make donations, view donation history, join programmes, and receive donation receipts.

The system also provides an **Executive Admin Dashboard** where administrators can manage donations, users, causes, programmes, NGO partners, corporate partners, queries, media, reports, FAQs, site settings, and audit activities.

This project was designed and developed **independently by Muhammad Ashhad** as a complete full-stack ASP.NET Core MVC application.
